# Ibasho

**A place where you belong. A world we build together.**

Ibasho takes its name from the Japanese word 居場所: a place where someone feels they belong and can be themselves.

Ibasho is an evolving browser-based virtual world. It begins with one welcoming palace or villa: a library, music room, creative studio, courtyard, fireplace lounge, gardens and rooftops. People will eventually be able to enter as avatars, explore, meet, talk and share experiences.

The longer-term ambition is to grow from one building into a community-created village, with homes, gardens, shared spaces and ways for inhabitants to shape their world.

## Guiding ideas

- Belonging before scale.
- People and shared experiences before complex systems.
- Creativity and agency for inhabitants.
- Build in small, testable steps.
- Prefer accessible tools and openly licensed assets where possible.

## First milestone

Create a small 3D room that runs in a browser, with a camera, lighting and a fireplace-like focal point. Add an avatar and movement next. Multiplayer comes after the basic experience works.

## Proposed technology

- Three.js for browser-based 3D.
- Vite and JavaScript for the frontend.
- Node.js and Socket.IO for later multiplayer.
- Git and GitHub for version control.

These are initial choices and can change when testing gives us a reason.
